2.1Multi-Hazard Risk Calculation Engine1. System geocodes user address to lat/lng coordinates
2. System loads FLOOD hazard GeoJSON data
3. System checks if user location within flood zones (point-in-polygon)
4. System calculates FLOOD risk: Inside zone = HIGH, Within 500m = MEDIUM, Else = LOW
5. System loads EARTHQUAKE fault line data
6. System calculates distance to nearest fault: <5km = HIGH, 5-15km = MEDIUM, >15km = LOW
7. System loads TYPHOON/STORM SURGE data
8. System checks coastal proximity + elevation: Coastal (<2km) + Low elevation (<5m) = HIGH
9. System loads LANDSLIDE susceptibility data
10. System checks: Hillside housing + High susceptibility zone = HIGH
11. System calculates HEAT risk: Urban area + Elderly/PWD = HIGH, Urban only = MEDIUM
12. System saves all 5 risk scores to database		Input Fields:
• User city and barangay (from profile)
• User housing type (from profile)
• User household composition (from profile)

Files:
• flood_zones.geojson (PAGASA data)
• earthquake_faults.geojson (PHIVOLCS data)
• typhoon_surge_zones.geojson (PAGASA data)
• landslide_susceptibility.geojson (MGB data)
• heat_vulnerability_zones.geojson		Output Display:
• Risk Dashboard with 5 color-coded badges:
- FLOOD: [HIGH/MEDIUM/LOW/NONE]
- EARTHQUAKE: [HIGH/MEDIUM/LOW/NONE]
- TYPHOON/STORM SURGE: [HIGH/MEDIUM/LOW/NONE]
- LANDSLIDE: [HIGH/MEDIUM/LOW/NONE]
- EXTREME HEAT: [HIGH/MEDIUM/LOW/NONE]
• Color coding: HIGH=red, MEDIUM=orange, LOW=green, NONE=gray
• Tooltip explanations for each risk level
• Link to detailed hazard map

Output Report: None		1. Address successfully geocodes to lat/lng coordinates
2. All 5 disaster risk scores calculate correctly
3. Risk scores saved to database with timestamp
4. Risk Dashboard displays all 5 risks with clear visual indicators
5. System explains what each risk level means

7. Tested with 10+ different addresses across Philippines		Sprint 3 (Weeks 5-6)
