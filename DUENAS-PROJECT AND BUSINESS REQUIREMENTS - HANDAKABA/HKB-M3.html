3.1GPT-4o Mini Personalized Checklist Generator1. System retrieves user profile data (household composition, location, housing type)
2. System retrieves all 5 risk scores
3. System constructs Gemini prompt with user context + risk data
4. System calls Google Gemini API with structured JSON output
5. Gemini analyzes household profile + risk scores
6. Gemini generates exactly 15 priority items tailored to user's situation
7. Each item includes: rank, category, task, personalized reason, estimated cost (pesos), urgency level
8. System validates response (must have exactly 15 items)
9. System saves all 15 items to database
10. System displays checklist to user
11. Items grouped by urgency: CRITICAL → HIGH → MEDIUM		Input Fields:
• User profile data (all fields from profile)
• All 5 risk scores (HIGH/MEDIUM/LOW/NONE)
• User request to generate/regenerate checklist

Files:
• AI system prompt template
• Fallback generic checklist (if API fails)		Output Display:
• Loading state: "Generating your personalized disaster preparedness plan... (may take 10-15 seconds)"
• 15 checklist item cards, each showing:
- Checkbox (for completion tracking)
- Task title (bold)
- Personalized reason (italic, explains WHY for YOUR household)
- Estimated cost in pesos
- Urgency badge (color-coded: CRITICAL=red, HIGH=orange, MEDIUM=yellow)
- Category tag (Documentation, Evacuation, Supplies, Planning, Communication)
• Items sorted by urgency
• "Regenerate Checklist" button
• Category filter dropdown

Output Report: None		1. System generates exactly 15 items (no more, no less)
